# Changelog

Все заметные изменения в этом проекте документируются в этом файле.

## [0.1.11] - 2026-04-11

### Исправлено
- Исправлена сериализация `DateTime`. Теперь значения сохраняются и загружаются без потери `DateTimeKind`,
  поэтому локальное время больше не смещается при сохранении, загрузке.
  Сохранена совместимость с чтением старого формата `DateTime`.
