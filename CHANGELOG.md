# Changelog

Изменения библиотеки по версиям.

## [0.1.13] — 2026-11-13

### Добавлено

- Поддержка браузера (WebAssembly): шифрование, хеширование и сериализация
  данных на устройстве пользователя.
- Поддержка Linux ARMv7 и ARM64, а также Alpine Linux на x64, ARMv7 и ARM64.
- Свойство `PlayerData.FileSystemSupported` для проверки доступности файловых операций.

### Изменено

- MessagePack обновлён до версии `3.1.12`.

### Исправлено

- Исправлены ошибки проверки данных при шифровании и расшифровке.
- Исправлена обработка ошибок при хешировании в Windows.
